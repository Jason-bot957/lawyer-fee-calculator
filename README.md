# 律师费测算

[打开计算器](https://jason-bot957.github.io/lawyer-fee-calculator/)

填标的额后，同时给出两类数字：**律师服务费参考**，以及向法院预交的 **诉讼费用参考**。整页一个 `index.html`，浏览器打开即可，不必安装。

## 能算什么

- **固定收费**：按《苏价费〔2017〕113号》涉及财产案件的分档累进，给出历史参考区间。该文件试行期满，现行律师服务收费是市场调节价，不能再写成政府指导价。
- **风险代理**：按司发通〔2021〕87号核对禁止范围，并以最终实现债权或减免债务金额为基数，校验 18%／15%／12%／9%／6% 分段最高限额。页面费率可改，没有法定最低费率。
- **诉讼费用**：案件受理费、财产保全费，依据《诉讼费用交纳办法》；江苏部分非财产案件定额按苏发改收费发〔2025〕381号。

右侧会列出分段明细。需要对外报价时，可复制条款草案或报价函草案。

## 怎么用

1. 选「固定收费」或「风险代理」
2. 填诉讼请求金额
3. 需要时展开「报价参数」：代理阶段、案型、保全、增值税、风险费率
4. 看右侧区间；可复制结果、条款或报价函

本地使用：下载本仓库，双击 `index.html`。

## 注意

测算只供讨论。律师费以委托合同为准，诉讼费用以法院缴费通知为准。

页面底部「计算依据与效力说明」列了法源链接，核验日期 2026-09-20。
